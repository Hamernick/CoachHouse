# Particle Event calendar extension

This section documents the Event calendar addition, not the complete application schema.

- Canonical Events: validated Activity Event widgets in `organization_workspace_boards.state.particleGraph`; projected into the internal calendar without duplicate event rows.
- `organization_workspace_calendar_revisions`: `org_id UUID PRIMARY KEY` referencing `organizations(user_id)` with cascade; `revision BIGINT > 0`; `updated_at TIMESTAMPTZ`. One small invalidation signal per organization, no Event content.
- Forced RLS, authenticated organization-scoped SELECT only, no anonymous access or client writes. The transactional board trigger checks calendar permissions and increments signals only for semantic Event changes. Only this signal table is published to Realtime.
- Migration/rollback and verification: [receipt](plans/2026-10-14-particle-event-calendar-migration-receipt.md).
